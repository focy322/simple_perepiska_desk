## Структура проекта

Весь исходный код приложения разделен на логические компоненты и находится в папке `src/`:
- `controllers/` — Контроллеры, которые связывают UI с бизнес-логикой и обрабатывают пользовательский ввод.
- `services/` — Сервисы, выполняющие сетевые запросы и основную бизнес-логику (авторизация, отправка сообщений, работа с файлами).
- `models/` — Qt-модели для отображения списков (чаты, сообщения, результаты поиска).
- `delegates/` — Делегаты для кастомной отрисовки элементов списков (например, красивое отображение сообщений).
- `widgets/` — Пользовательские виджеты (например, поле с поддержкой Drag & Drop файлов).
- `utils/` — Утилиты и вспомогательные функции, общие константы (роуты API, типы ошибок).
- `resources/` — Иконки, звуки и файлы ресурсов Windows (`.rc`, `.qrc`).

## Требования к окружению (Windows)

Для сборки проекта на Windows мы используем **MSYS2** (окружение UCRT64).
Вам понадобится установить:
1. Компилятор **GCC** (UCRT64)
2. **CMake** и **Ninja**
3. **Qt 6** (Core, Gui, Network, WebSockets, Multimedia, Widgets)
4. **Git** (для подтягивания сторонних библиотек, таких как `qtkeychain`)

### Быстрая установка зависимостей

В корне проекта есть скрипт `setup_env.ps1`, который автоматически скачает нужные пакеты и предложит добавить пути в `PATH`.
1. Установите [MSYS2](https://www.msys2.org/) (по умолчанию в `C:\msys64`).
2. Откройте PowerShell в папке проекта.
3. Запустите скрипт:
   ```powershell
   .\setup_env.ps1
   ```
4. Согласитесь на добавление путей в `PATH` (если будет предложено) и **перезапустите IDE**.

## Настройка VS Code

Установите следующие расширения в Visual Studio Code:
- **C/C++** (от Microsoft) — для автодополнения и подсветки синтаксиса.
- **CMake Tools** (от Microsoft) — для удобной интеграции CMake в редактор.

### Сборка проекта

1. Откройте папку проекта в VS Code.
2. Расширение **CMake Tools** автоматически обнаружит файл `CMakeLists.txt`.
3. В нижней панели VS Code нажмите на выбор компилятора (`No Kit Selected` или текущий) и выберите:
   `GCC <версия> x86_64-w64-mingw32` (убедитесь, что он ведет в `C:\msys64\ucrt64\bin\gcc.exe`).
4. Нажмите кнопку **Build** (или `F7`) в нижней панели, чтобы собрать проект.
5. Нажмите кнопку **Run** (или `Shift + F5`) для запуска приложения.

### Выбор типа сборки (Debug / Release)

Чтобы поменять тип сборки в VS Code:
1. В нижней панели найдите кнопку, на которой написано **CMake: [Debug]** или **CMake: [Release]**.
2. Нажмите на неё (или используйте палитру команд `Ctrl+Shift+P` -> `CMake: Select Variant`).
3. Выберите нужный тип (например, `Release`).
4. Пересоберите проект (кнопка **Build**).
