## Структура проекта

Весь исходный код приложения разделен на логические компоненты и находится в папке `src/`:
- `controllers/` — Контроллеры, которые связывают UI с бизнес-логикой и обрабатывают пользовательский ввод.
- `services/` — Сервисы, выполняющие сетевые запросы и основную бизнес-логику.
- `models/` — Qt-модели для отображения списков.
- `delegates/` — Делегаты для кастомной отрисовки элементов списков.
- `widgets/` — Пользовательские виджеты.
- `utils/` — Утилиты и вспомогательные функции, общие константы.

`resources/` — Иконки, звуки и файлы ресурсов Windows.

## Установка зависимостей (Qt)

Проект использует фреймворк Qt (версии 6.x) и компилятор MinGW.

1. Скачайте и установите **Qt** через [Qt Online Installer](https://www.qt.io/download).
2. При установке выберите нужную версию Qt (например, Qt 6.11).
3. В списке компонентов обязательно отметьте компилятор **MinGW 64-bit**.

## Настройка VS Code

Установите следующие расширения:
- **C/C++ Extension Pack** (Microsoft)
- **CMake Tools** (Microsoft)
- **Qt C++ Extension Pack** (Qt Group) — официальные инструменты для работы с Qt.

### Регистрация пути к Qt

Чтобы VS Code нашел нужные библиотеки и утилиты (qmake, moc, uic):
1. Откройте палитру команд (`Ctrl + Shift + P`) и введите `Qt: Register Qt installation`.
2. Укажите путь к компилятору внутри вашей папки с установленным Qt.
   *(Пример пути: `C:\Qt\6.11.0\mingw_64`)*

### Сборка проекта

1. Откройте папку проекта в VS Code.
2. Нажмите `Ctrl + Shift + P` и введите `CMake: Select a Kit` (или нажмите на текущий компилятор в самом низу окна).
3. Выберите Kit, который содержит слова "MinGW" и указывает на папку установки Qt (например, `Qt 6.11.1 MinGW 64-bit` или путь `C:\Qt\...`).
4. Нажмите кнопку **Build** (или `F7`) в нижней синей панели для сборки.
5. Нажмите кнопку **Run** (или `Shift + F5`) для запуска приложения.

### Выбор типа сборки (Debug / Release)

Для переключения между Debug и Release:
1. Нажмите `Ctrl + Shift + P` -> `CMake: Select Variant`.
2. Выберите нужный тип (`Release` или `Debug`).
3. Нажмите кнопку **Build** для пересборки.
